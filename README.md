# **Reverse Breathing**

Reverse Breathing is a simple plugin that reverses the *breathing system* for selected players.

### Features

* _Selected_ players can breathe underwater.
* _Selected_ players lose air while on land.
* `Rain` allows selected players to breathe.
* `Water Breathing` and `Conduit Power` allows selected players to breathe on land.
* `Respiration` enchantment is supported.
* Players automatically take drowning damage when their air reaches zero.
* Only _selected_ players are affected; everyone else keeps normal Minecraft breathing mechanics.
* Player selection is **persistent** and stored in the plugin configuration.

### Commands

* `/breathing add <player>` - Add a player to the reverse breathing system.
* `/breathing remove <player>` - Remove a player from the reverse breathing system.
* `/breathing list` - Display all players currently using the reverse breathing system.
